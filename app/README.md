# BuildHub 🏗️

Android-приложение для поиска и заказа строительных услуг с ролевой моделью пользователей (клиент, менеджер, администратор).

---

## Стек технологий

- **Язык:** Java
- **Платформа:** Android (minSdk 24)
- **Backend:** Supabase (REST API, Auth, Realtime)
- **Сборка:** Gradle
- **Тестирование:** JUnit 4

---

## Функциональность

- Авторизация и регистрация с разграничением ролей
- Каталог услуг с поиском и фильтрацией по категориям
- Оформление и отслеживание заказов
- Чат между клиентом и менеджером в реальном времени
- Панель менеджера: управление заказами и услугами
- Панель администратора: управление пользователями и контентом
- Просмотр профиля и отзывов

---

## Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/taranovaleksay-pixel/BuildHub.git
   ```

2. Открыть проект в **Android Studio**

3. Дождаться синхронизации Gradle

4. Запустить на эмуляторе или реальном устройстве (Android 7.0+)

## Структура проекта

```
app/src/main/java/com/example/coursach/
├── activities/        # Экраны приложения
│   ├── LoginActivity.java
│   ├── RegisterActivity.java
│   ├── SplashActivity.java
│   ├── ServiceDetailActivity.java
│   ├── ChatActivity.java
│   ├── ManagerActivity.java
│   ├── AdminActivity.java
│   └── ProfileActivity.java
├── adapters/          # RecyclerView адаптеры
├── fragments/         # Фрагменты (каталог, заказы, профиль)
├── models/            # Модели данных (Service, Order, Profile, ChatMessage)
├── network/           # SupabaseClient — работа с API
└── utils/             # Константы и вспомогательные классы
```
